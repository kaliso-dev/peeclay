# 1331 Linda Flora Drive — scroll tour

Static one-page site: a scroll-driven tour of 1331 Linda Flora Drive, Bel Air, in 15 chapters (each room plays full screen, then steps aside for its details).

- `index.html` — the whole page (HTML, CSS and JS inline; smooth scroll via Lenis from jsDelivr, fonts from Google Fonts)
- `frames/Pxx/F_0000.webp … F_0047.webp` — the 48 rendered frames of each room
- `img/` — finished still renders used across the page

No build step. To preview locally, open `index.html` in a browser. Netlify publishes the repository root as is (`netlify.toml`).

Images are computer-generated visualisations; furnishings and finishes are illustrative.
